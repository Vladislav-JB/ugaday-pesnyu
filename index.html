    Как устроен сайт

    Откуда песни

    Миллионы треков без своего хранилища: отрывки по 30 секунд берутся из официального каталога iTunes / Apple Music через открытый API. Плейлисты собираются автоматически по исполнителям и жанрам.

    Права

    Сайт не хранит и не раздаёт музыку: играет только официальные превью, которые сервисы дают для продвижения треков, и у каждой песни есть ссылка на полную версию. Для полностью «чистого» режима можно подключить музыку с лицензией royalty-free.

    Что можно добавить

    Аккаунты и общий рейтинг игроков, комнаты для игры с друзьями, свои плейлисты, ежедневное задание, монетизацию через рекламу или подписку.
